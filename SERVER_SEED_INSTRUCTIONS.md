# Инструкция по выполнению seed на сервере

## Команды для выполнения

### Шаг 1: Выполнить миграции
```bash
php artisan migrate
```
Это добавит поле `user_id` в таблицы `categories`, `products` и `units`.

### Шаг 2: Запустить seeder
```bash
php artisan db:seed --class=PirogiSeeder
```

Seeder автоматически:
- ✅ Найдет первого пользователя в системе
- ✅ Создаст 8 категорий с `user_id`
- ✅ Создаст папки для каждой категории в медиа-библиотеке
- ✅ Создаст 4 единицы измерения с `user_id`
- ✅ Создаст ~73 товара с `user_id`
- ✅ Скачает изображения с https://pirogi.ru
- ✅ Сохранит изображения в папки категорий
- ✅ Привяжет изображения к товарам

## Требования

1. **Файлы данных должны быть на месте:**
   - `storage/pirogi_data.json` - данные о категориях и товарах
   - `storage/pirogi_products_images.json` - карта сопоставления товаров с изображениями

2. **Права доступа:**
   - Папка `public/upload` должна иметь права на запись (755 или 777)

3. **Интернет-соединение:**
   - Сервер должен иметь доступ к https://pirogi.ru

4. **Пользователь в системе:**
   - Должен существовать хотя бы один пользователь (Seeder использует первого)

## Время выполнения

Seeder работает 5-10 минут из-за скачивания ~70 изображений.

Если прерывается по таймауту:
- Запустите через CLI: `php artisan db:seed --class=PirogiSeeder`
- Или увеличьте `max_execution_time` в `php.ini`

## Ожидаемые результаты

После выполнения:
- ✅ 8 категорий
- ✅ ~73 товара
- ✅ ~71 товар с изображениями
- ✅ 4 единицы измерения
- ✅ 8 папок категорий в медиа-библиотеке
- ✅ ~250+ медиа файлов (оригиналы + WebP + варианты размеров)

## Структура сохранения изображений

Изображения сохраняются в:
```
public/upload/common/
  ├── salaty/          (Салаты)
  ├── supy/            (Супы)
  ├── vtorye-bliuda/   (Вторые блюда)
  ├── garniry/         (Гарниры)
  ├── pirogi-sytnye/   (Пироги сытные)
  ├── pirogi-sladkie/  (Пироги сладкие)
  ├── vypecka/         (Выпечка)
  └── bliny/           (Блины)
```

## Проверка результатов

После выполнения seeder проверьте в админ-панели:
- `/admin/categories` - должны быть 8 категорий
- `/admin/products` - должны быть ~73 товара, большинство с изображениями
- `/admin/units` - должны быть 4 единицы измерения
- `/admin/media` - должны быть папки категорий с изображениями

## Если что-то пошло не так

1. **Проверьте логи:** `storage/logs/laravel.log`
2. **Проверьте файлы данных:** убедитесь, что `storage/pirogi_data.json` и `storage/pirogi_products_images.json` существуют
3. **Проверьте доступность сайта:** `curl -I https://pirogi.ru`
4. **Проверьте пользователя:** `php artisan tinker` → `App\Models\User::count()`

## Повторный запуск

Seeder использует `firstOrCreate`, поэтому можно запускать его несколько раз - дубликаты не создадутся. Если нужно пересоздать данные, сначала удалите существующие записи.
