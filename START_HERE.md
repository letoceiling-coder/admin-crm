# 🚀 НАЧНИТЕ ЗДЕСЬ

## Локально (перед деплоем):

### Шаг 1: Собрать данные о питательных веществах

**Вариант A: Node.js (автоматически)**
```bash
npm install
npm run collect
```

**Вариант B: Без Node.js (через браузер)**
1. Откройте `scrape_nutritional_data_local.html` в браузере
2. Скопируйте содержимое `storage/pirogi_data.json` в скрипт
3. Нажмите "Начать сбор данных"
4. Скопируйте обновленный JSON обратно в `storage/pirogi_data.json`

### Шаг 2: Задеплоить на сервер

Загрузите все файлы, включая обновленный `storage/pirogi_data.json`

## На сервере (ОДНА КОМАНДА):

```bash
php artisan db:seed --class=PirogiSeeder
```

**ГОТОВО!** Все создано автоматически.
