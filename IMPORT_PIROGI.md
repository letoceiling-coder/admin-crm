# Инструкция по импорту данных с pirogi.ru

## Подготовка

1. **Убедитесь, что все миграции выполнены:**
   ```bash
   php artisan migrate
   ```
   
   Если есть ошибки с миграциями folders, выполните их вручную или исправьте проблему.

2. **Проверьте наличие файла с данными:**
   - Файл должен находиться в `storage/pirogi_data.json`
   - Данные уже собраны с сайта pirogi.ru

## Запуск импорта

Запустите seeder:
```bash
php artisan db:seed --class=PirogiSeeder
```

Или раскомментируйте строку в `database/seeders/DatabaseSeeder.php`:
```php
PirogiSeeder::class,
```
И запустите:
```bash
php artisan db:seed
```

## Что будет создано

✅ **8 категорий:**
- Салаты
- Супы
- Вторые блюда
- Гарниры
- Пироги сытные
- Пироги сладкие
- Выпечка
- Блины

✅ **~70 товаров** с:
- Названиями
- Ценами
- Привязкой к категориям
- Единицами измерения

✅ **Единицы измерения** (автоматически определяются):
- Порция (порц.) - для салатов, супов, вторых блюд, гарниров
- Штука (шт.) - для блинов, слойков, выпечки, маленьких пирогов
- Килограмм (кг) - для больших пирогов (>1000 руб)

✅ **Изображения товаров:**
- Seeder пытается найти и скачать изображения с сайта pirogi.ru
- Если изображение найдено, оно сохраняется в медиа-библиотеку и привязывается к товару
- Если изображение не найдено, товар создается без изображения (можно добавить позже)

## Логирование

Seeder выводит информацию о процессе:
- Созданные категории
- Созданные единицы измерения
- Созданные товары
- Успешно сохраненные изображения
- Предупреждения о ненайденных изображениях

## После импорта

Проверьте созданные данные в админ-панели:
- `/admin/categories` - список категорий
- `/admin/products` - список товаров  
- `/admin/units` - список единиц измерения

## Примечания

- Seeder использует `firstOrCreate`, поэтому можно запускать его несколько раз - дубликаты не создадутся
- Изображения ищутся по стандартным путям на сайте pirogi.ru
- Если нужно добавить изображения вручную, используйте медиа-библиотеку в админ-панели
