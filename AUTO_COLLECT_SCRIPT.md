# Автоматический сбор данных через браузер MCP

```json
{

  "fat": 4.5,
  "carbs": 25,
  "calories": 180
}
```

Данные добавлены в `storage/pirogi_data.json`.

## Для сбора остальных товаров:

### Вариант 1: HTML скрипт (РЕКОМЕНДУЕТСЯ)

1. Откройте `scrape_nutritional_data_local.html` в браузере
2. Скопируйте содержимое `storage/pirogi_data.json`
3. Запустите сбор - скрипт соберет данные для всех товаров
4. Скопируйте обновленный JSON обратно в файл

### Вариант 2: Ручной сбор через консоль браузера

Для каждого товара:
1. Откройте страницу товара на pirogi.ru
2. Откройте консоль (F12)
3. Выполните скрипт из `scrape_nutritional_data_manual.md`
4. Добавьте результат в JSON

## После сбора всех данных:

Задеплойте обновленный `storage/pirogi_data.json` на сервер.

## На сервере:

```bash
php artisan db:seed --class=PirogiSeeder
```

**Готово!** Все создано со всеми данными.
