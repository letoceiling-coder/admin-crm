# Финальное решение: Одна команда для всего

## Локально (перед деплоем):

### Вариант 1: Node.js (автоматически)

```bash
# 1. Установить зависимости (один раз)
npm install

# 2. Собрать данные (одна команда)
npm run collect
```

Скрипт автоматически:
- ✅ Откроет браузер
- ✅ Соберет данные о питательных веществах со всех товаров
- ✅ Обновит `storage/pirogi_data.json`

### Вариант 2: Без Node.js (через браузер)

1. Откройте `scrape_nutritional_data_local.html` в браузере
2. Вставьте JSON из `storage/pirogi_data.json`
3. Нажмите "Начать сбор данных"
4. Скопируйте обновленный JSON обратно в файл

## Деплой на сервер:

### Загрузите файлы:
- ✅ `storage/pirogi_data.json` (с собранными данными)
- ✅ Все остальные файлы проекта

### На сервере (одна команда):

```bash
php artisan db:seed --class=PirogiSeeder
```

**Готово!** Все таблицы созданы со всеми данными:
- ✅ Категории
- ✅ Товары
- ✅ Единицы измерения
- ✅ Изображения
- ✅ Питательные вещества
