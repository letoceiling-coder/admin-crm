Сбор питательных веществ с pirogi.ru

Инструкция:

  1. Откройте https://pirogi.ru/ в новой вкладке
  2. Вставьте JSON данные товаров в поле ниже (из файла storage/pirogi_data.json)
  3. Нажмите "Начать сбор данных"
  4. Скрипт будет открывать страницы товаров и собирать данные
  5. После завершения скопируйте обновленный JSON и сохраните в storage/pirogi_data.json на сервере
