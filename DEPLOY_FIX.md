# ✅ Исправление деплоя

## Проблема:
Ошибка: `npm error Missing script: "build"`

## Решение:

### Вариант 1: Использовать флаг --skip-build (рекомендуется)

```bash
php artisan deploy --skip-build
```

Это пропустит сборку фронтенда, если она уже выполнена или не требуется.

### Вариант 2: Установить зависимости Vite

Если нужно собирать фронтенд, установите зависимости:

```bash
npm install
```

Это установит Vite и необходимые плагины, после чего `npm run build` будет работать.

## Обновленный package.json:

В `package.json` добавлены:
- Скрипты `dev` и `build` для Vite
- DevDependencies для Vite, laravel-vite-plugin и @vitejs/plugin-vue

## Рекомендация:

Используйте `--skip-build` если:
- Фронтенд уже собран
- Сборка выполняется на сервере
- Не нужно собирать фронтенд при каждом деплое

Используйте обычный деплой (`php artisan deploy`) если:
- Нужно собрать фронтенд перед деплоем
- Все зависимости установлены (`npm install`)
