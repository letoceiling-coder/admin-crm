# Команды для выполнения seed на сервере

## Быстрая инструкция

### 1. Выполнить миграции
```bash
php artisan migrate
```

### 2. Обновить user_id для существующих записей (если есть)
```bash
php update_existing_user_id.php
```

### 3. Запустить seeder
```bash
php artisan db:seed --class=PirogiSeeder
```

## Полная последовательность команд

```bash
# 1. Перейти в директорию проекта
cd /path/to/crm

# 2. Выполнить миграции
php artisan migrate

# 3. Обновить user_id для существующих записей (если нужно)
php update_existing_user_id.php

# 4. Запустить seeder (это займет время из-за скачивания изображений)
php artisan db:seed --class=PirogiSeeder

# 5. Проверить результаты
php check_seed_results.php
```

## Что будет создано

- ✅ **8 категорий** с user_id = 1 (или первый пользователь)
- ✅ **~73 товара** с user_id и привязкой к категориям
- ✅ **4 единицы измерения** с user_id
- ✅ **8 папок** в медиа-библиотеке (по одной на категорию)
- ✅ **~180+ медиа файлов** (изображения товаров в папках категорий)

## Важно

1. **Файлы данных должны быть на месте:**
   - `storage/pirogi_data.json`
   - `storage/pirogi_products_images.json`

2. **Права на запись:**
   - Папка `public/upload` должна иметь права на запись

3. **Интернет-соединение:**
   - Сервер должен иметь доступ к https://pirogi.ru для скачивания изображений

4. **Время выполнения:**
   - Seeder может работать 5-10 минут из-за скачивания ~70 изображений
   - Если прерывается по таймауту, запустите через CLI или увеличьте `max_execution_time`

## Проверка после выполнения

```bash
php check_seed_results.php
```

Должно показать:
- Категории: 8
- Товары: 73
- Товары с изображениями: 70+
- Единицы измерения: 4
- Медиа файлы: 180+

## Если что-то пошло не так

1. Проверьте логи: `storage/logs/laravel.log`
2. Проверьте наличие файлов данных в `storage/`
3. Проверьте доступность сайта pirogi.ru
4. Убедитесь, что первый пользователь существует в базе данных
