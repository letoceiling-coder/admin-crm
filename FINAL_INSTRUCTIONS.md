# ✅ ФИНАЛЬНАЯ ИНСТРУКЦИЯ

## Локально (перед деплоем):

### Запустите скрипт подготовки:

```bash
prepare_for_deploy.bat
```

Или вручную:
```bash
npm install
npm run collect
```

**Это обновит `storage/pirogi_data.json` с данными о питательных веществах.**

## Деплой:

Загрузите на сервер:
- ✅ Все файлы проекта
- ✅ **Обновленный `storage/pirogi_data.json`** (с собранными данными)

## На сервере (ОДНА КОМАНДА):

```bash
php artisan db:seed --class=PirogiSeeder
```

**ГОТОВО!** Все создано автоматически:
- ✅ Категории
- ✅ Товары
- ✅ Единицы измерения
- ✅ Изображения
- ✅ Питательные вещества

## Что будет создано:

- 4 единицы измерения
- 73 товара

- Все питательные вещества (из JSON)

## Если Node.js не установлен:

Используйте `scrape_nutritional_data_local.html` в браузере для сбора данных вручную.
