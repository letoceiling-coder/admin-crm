## План действий

### Вариант 1: Если вы на сервере (production)

#### Шаг 1: Выполнить миграции
```bash
php artisan migrate
```

#### Шаг 2: Запустить seeder (обновит товары, но поля питательных веществ будут пустыми)
```bash
php artisan db:seed --class=PirogiSeeder
```

#### Шаг 3: (Опционально) Собрать данные о питательных веществах
- Скачайте `scrape_nutritional_data_local.html` на локальный компьютер
- Откройте в браузере
- Скопируйте `storage/pirogi_data.json` с сервера
- Соберите данные через HTML скрипт
- Загрузите обновленный JSON обратно на сервер
- Запустите seeder снова
