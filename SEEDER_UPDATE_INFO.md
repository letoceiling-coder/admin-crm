# Информация о работе PirogiSeeder

## Поведение при повторном запуске

При запуске `php artisan db:seed --class=PirogiSeeder`:

### ✅ Что происходит:

1. **Категории** - используется `firstOrCreate`:
   - Если категория существует (по slug) → **НЕ создается заново, НЕ обновляется**
   - Если категории нет → создается новая

2. **Товары** - используется `firstOrCreate` + обновление:
   - Если товар существует (по slug) → **ОБНОВЛЯЕТСЯ** новыми данными:
     - Питательные вещества (weight, protein, fat, carbs, calories)
     - Если в данных есть новые значения, они обновятся
   - Если товара нет → создается новый со всеми данными
   - Изображения скачиваются только если у товара еще нет изображения (`image_id`)

3. **Единицы измерения** - используется `firstOrCreate`:
   - Если единица существует (по short_name) → **НЕ создается заново, НЕ обновляется**
   - Если единицы нет → создается новая

4. **Медиа файлы** - создаются только если:
   - У товара еще нет главного изображения
   - Изображение найдено на сайте

### 📝 Важно:

- **Дубликаты НЕ создаются** - благодаря `firstOrCreate` по уникальным полям (slug для товаров/категорий)
- **Существующие товары ОБНОВЛЯЮТСЯ** новыми полями (питательные вещества, вес)
- **Изображения НЕ перезаписываются** - если у товара уже есть изображение, новое не скачивается

### 🔄 Для полного обновления всех данных:

Если нужно пересоздать все данные с нуля:

```bash
# Очистить существующие данные
php artisan tinker
```

```php
DB::table('product_media')->delete();
DB::table('products')->delete();
DB::table('categories')->delete();
DB::table('units')->delete();
// Медиа файлы нужно удалить вручную из public/upload/common/
exit
```

Затем запустить seeder заново.

### 📊 Новые поля в товарах:

После выполнения миграции `add_nutritional_info_to_products_table` и обновления seeder, товары будут содержать:
- `weight` - вес порции в граммах
- `protein` - белки в граммах
- `fat` - жиры в граммах  
- `carbs` - углеводы в граммах
- `calories` - калорийность в ккал

Эти данные будут обновляться при повторном запуске seeder, если они есть в исходных данных.
