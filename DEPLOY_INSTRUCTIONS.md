# Инструкция по деплою и обновлению данных

## После выполнения deploy

### Шаг 1: Выполнить миграции

```bash
php artisan migrate
```

Это добавит новые поля в таблицу `products`:
- `weight` - вес порции в граммах
- `protein` - белки в граммах
- `fat` - жиры в граммах
- `carbs` - углеводы в граммах
- `calories` - калорийность в ккал

### Шаг 2: Обновить файл с данными (если нужно)

Если вы собрали данные о питательных веществах локально:

1. **Загрузите обновленный `storage/pirogi_data.json`** на сервер
   - Файл должен содержать поля `weight`, `protein`, `fat`, `carbs`, `calories` для товаров

2. **Или оставьте существующий файл**, если данные еще не собраны
   - Товары будут обновлены, но поля питательных веществ останутся пустыми
   - Данные можно добавить позже

### Шаг 3: Запустить seeder для обновления товаров

```bash
php artisan db:seed --class=PirogiSeeder
```

**Что произойдет:**
- ✅ Существующие товары будут **обновлены** новыми полями (если они есть в JSON)
- ✅ Новые товары будут созданы (если их еще нет)
- ✅ Изображения будут скачаны только для товаров без изображений
- ✅ Категории и единицы измерения не будут дублироваться

**Важно:** Seeder использует `firstOrCreate`, поэтому:
- Дубликаты не создаются
- Существующие записи обновляются только новыми полями
- Изображения не перезаписываются

### Шаг 4: Проверить результаты

#### Проверка через админ-панель:

1. Откройте `/admin/products`
2. Откройте любой товар для редактирования
3. Проверьте раздел "Вес и питательные вещества":
   - Должны быть поля: Вес порции, Калорийность, Белки, Жиры, Углеводы
   - Если данные собраны - поля будут заполнены
   - Если данные не собраны - поля будут пустыми

#### Проверка через базу данных:

```bash
php artisan tinker
```

## Если нужно собрать данные о питательных веществах

### Вариант 1: Использовать HTML скрипт (локально)

1. Скачайте `scrape_nutritional_data_local.html` на локальный компьютер
2. Откройте в браузере
3. Скопируйте `storage/pirogi_data.json` с сервера
4. Вставьте в HTML скрипт и запустите сбор
5. Скопируйте обновленный JSON обратно на сервер
6. Запустите seeder снова

### Вариант 2: Ручное добавление в JSON

Отредактируйте `storage/pirogi_data.json` и добавьте к каждому товару:

```json
{
  "name": "Салат «Мимоза»",
  "weight": 250,
  "protein": 8,
  "fat": 10,
  "carbs": 35.5,
  "calories": 255
}
```

Затем запустите seeder снова.

## Полная последовательность команд для деплоя

```bash
# 1. Перейти в директорию проекта
cd /path/to/crm

# 2. Выполнить миграции
php artisan migrate

# 3. (Опционально) Загрузить обновленный pirogi_data.json
# Если вы собрали данные локально, загрузите файл на сервер

# 4. Запустить seeder для обновления товаров
php artisan db:seed --class=PirogiSeeder

# 5. Проверить результаты
php artisan tinker
# Выполнить команды проверки (см. выше)
```

## Важные замечания

1. **Миграции безопасны** - они только добавляют новые поля, не удаляют данные

2. **Seeder безопасен** - можно запускать несколько раз:
   - Дубликаты не создаются
   - Существующие данные не удаляются
   - Обновляются только новые поля

3. **Изображения** - скачиваются только для товаров без изображений

4. **Данные о питательных веществах** - опциональны, можно добавить позже

## Откат изменений (если нужно)

Если нужно откатить миграцию:

```bash
php artisan migrate:rollback --step=1
```

Это удалит поля `weight`, `protein`, `fat`, `carbs`, `calories` из таблицы `products`.

**Внимание:** Данные в этих полях будут потеряны!

## Проверка статуса миграций

```bash
php artisan migrate:status
```

Проверьте, что миграция `add_nutritional_info_to_products_table` выполнена.
