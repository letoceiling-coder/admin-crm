# ⚠️ ВАЖНО: Сбор данных о питательных веществах

## Проблема с автоматическим сбором

Автоматический сбор данных через Puppeteer может работать медленно или падать из-за:
- Таймаутов загрузки страниц
- Блокировок сайта
- Медленного интернета

## Решение: Ручной сбор через браузер (РЕКОМЕНДУЕТСЯ)

### Используйте HTML скрипт:

1. **Откройте `scrape_nutritional_data_local.html` в браузере**

2. **Скопируйте содержимое `storage/pirogi_data.json`** в поле скрипта

3. **Нажмите "Начать сбор данных"**
   - Скрипт откроет страницы товаров
   - Соберет данные автоматически
   - Обновит JSON

4. **Скопируйте обновленный JSON** обратно в `storage/pirogi_data.json`

5. **Задеплойте обновленный JSON на сервер**

## Альтернатива: Сбор вручную

Если автоматический сбор не работает, можно собрать данные вручную:

1. Откройте страницу товара на pirogi.ru
2. Откройте консоль браузера (F12)
3. Выполните скрипт из `scrape_nutritional_data_manual.md`
4. Скопируйте результат и добавьте в JSON

## На сервере (после сбора данных):

```bash
php artisan db:seed --class=PirogiSeeder
```

**Одна команда - все создастся автоматически!**
