# Seeder полностью переписан

## Что изменилось

### ✅ Полная очистка перед импортом

При запуске `php artisan db:seed --class=PirogiSeeder`:

1. **Очищаются таблицы:**
   - `product_media` - связи товаров с медиа
   - `products` - все товары
   - `categories` - все категории
   - `units` - все единицы измерения
   - `media` - медиа файлы пользователя (из папок категорий)
   - `folders` - папки категорий

2. **Удаляются файлы:**
   - Физически удаляются изображения из файловой системы
   - Удаляются WebP версии
   - Удаляются варианты размеров

3. **Создаются заново:**
   - Категории
   - Единицы измерения
   - Товары (со всеми данными, включая питательные вещества)
   - Папки категорий
   - Медиа файлы

### ✅ Использование create вместо firstOrCreate

Все записи создаются заново через `create()`, а не `firstOrCreate()`, так как данные очищаются перед импортом.

### ✅ Улучшенное логирование

- Показывает процесс очистки
- Показывает создание категорий, единиц, товаров
- Показывает статистику в конце
- Показывает количество товаров с данными о питательных веществах

## Использование

```bash
php artisan db:seed --class=PirogiSeeder
```

## Что будет создано

- ✅ 8 категорий
- ✅ 4 единицы измерения
- ✅ ~73 товара
- ✅ ~71 товар с изображениями
- ✅ 8 папок категорий
- ✅ ~250+ медиа файлов

## Важно!

⚠️ **При каждом запуске seeder:**
- Все существующие данные удаляются
- Все создается заново
- Файлы изображений удаляются физически

Это означает, что:
- Можно безопасно запускать несколько раз
- Данные всегда синхронизированы с JSON
- Нет дубликатов

## Структура данных

Seeder загружает данные из `storage/pirogi_data.json` и создает:
- Категории с `user_id`
- Товары с `user_id` и питательными веществами (если есть в JSON)
- Единицы измерения с `user_id`
- Медиа файлы в папках категорий

## Питательные вещества

Если в `storage/pirogi_data.json` есть поля:
- `weight` - вес порции
- `protein` - белки
- `fat` - жиры
- `carbs` - углеводы
- `calories` - калорийность

Они будут автоматически добавлены к товарам.
