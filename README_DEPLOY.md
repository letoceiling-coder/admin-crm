## 📋 Быстрый старт:

### 1. Загрузите на сервер:
- Все файлы проекта
- **`storage/pirogi_data.json`** (обновленный)

### 2. Выполните на сервере:

```bash
php artisan migrate --force
php artisan db:seed --class=PirogiSeeder
```

**ГОТОВО!** Все данные созданы автоматически.
