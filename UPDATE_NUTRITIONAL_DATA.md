# Инструкция по обновлению питательных веществ и веса товаров

## Проблема

При запуске `php artisan db:seed --class=PirogiSeeder` товары обновляются, но новые поля (`weight`, `protein`, `fat`, `carbs`, `calories`) остаются пустыми, потому что в файле `storage/pirogi_data.json` нет этих данных.

## Решение

### Шаг 1: Собрать данные с сайта pirogi.ru

Запустите скрипт для парсинга страниц товаров:

```bash
php scrape_nutritional_data.php
```

Скрипт:
- ✅ Загружает страницы товаров с pirogi.ru
- ✅ Парсит HTML для извлечения:
  - Веса порции (`<div class="id-weight">`)
  - Белков, жиров, углеводов, калорийности (`<div class="id-params-item">`)
- ✅ Обновляет файл `storage/pirogi_data.json` с новыми данными
- ✅ Пропускает товары, у которых данные уже есть

**Время выполнения:** ~5-10 минут (зависит от количества товаров и скорости интернета)

### Шаг 2: Обновить базу данных

После сбора данных запустите seeder:

```bash
php artisan db:seed --class=PirogiSeeder
```

Seeder обновит существующие товары новыми данными о питательных веществах и весе.

## Что собирается

Скрипт собирает с каждой страницы товара:

1. **Вес порции** - из `<div class="id-weight">250 гр</div>`
2. **Белки** - из блока с заголовком "Белки"
3. **Жиры** - из блока с заголовком "Жиры"
4. **Углеводы** - из блока с заголовком "Углеводы"
5. **Калорийность** - из блока с заголовком "Калорийность"

## Пример вывода

```
[1/73] Салат «Мимоза»... ✓ (вес: 250г, Б: 8, Ж: 10, У: 35.5, ккал: 255)
[2/73] Сельдь под шубой... ✓ (вес: 200г, Б: 12, Ж: 15, У: 20, ккал: 280)
...
═══════════════════════════════════════
Готово!
Обновлено товаров: 65
Пропущено (уже есть данные): 0
Ошибок: 8
```

## Если скрипт не находит данные

Возможные причины:
1. Структура HTML на сайте изменилась
2. Товар не найден на странице категории
3. У товара нет страницы с детальной информацией

В этом случае данные можно добавить вручную в `storage/pirogi_data.json`:

```json
{
  "name": "Салат «Мимоза»",
  "weight": 250,
  "protein": 8,
  "fat": 10,
  "carbs": 35.5,
  "calories": 255
}
```

## Повторный запуск

Скрипт можно запускать несколько раз:
- Товары с уже собранными данными будут пропущены
- Только товары без данных будут обработаны
