# Одна команда на сервере - все создается автоматически

## Процесс:

### Локально (перед деплоем):

1. **Собрать данные о питательных веществах:**
   ```bash
   npm install
   npm run collect
   ```
   
   Это обновит `storage/pirogi_data.json` с данными о весе и питательных веществах.

2. **Задеплоить на сервер:**
   - Загрузите обновленный `storage/pirogi_data.json` на сервер
   - Загрузите все остальные файлы проекта

### На сервере (ОДНА КОМАНДА):

```bash
php artisan db:seed --class=PirogiSeeder
```

**ВСЕ!** Seeder автоматически:
- ✅ Очистит старые данные
- ✅ Создаст категории
- ✅ Создаст единицы измерения
- ✅ Создаст товары
- ✅ Скачает изображения
- ✅ Заполнит питательные вещества (из JSON)

## Важно:

**На сервере НЕ нужно:**
- ❌ Собирать данные
- ❌ Обновлять JSON
- ❌ Делать что-то еще

**Только одна команда:**
```bash
php artisan db:seed --class=PirogiSeeder
```

Все данные уже должны быть в `storage/pirogi_data.json` после локального сбора.

## Проверка:

После выполнения seeder проверьте:

```bash
php artisan tinker
```

```php
echo "Товары: " . App\Models\Product::count() . "\n";
echo "С весом: " . App\Models\Product::whereNotNull('weight')->count() . "\n";
echo "С белками: " . App\Models\Product::whereNotNull('protein')->count() . "\n";
exit
```

Если все правильно - все товары будут с данными о питательных веществах!
