# Инструкция по выполнению seed на сервере

## Шаги для выполнения на сервере

### 1. Выполнить миграции

```bash
php artisan migrate
```

Это создаст/обновит таблицы:
- `categories` (добавит `user_id`)
- `products` (добавит `user_id`)
- `units` (добавит `user_id`)

### 2. Очистить существующие данные (опционально)

Если нужно пересоздать данные заново:

```bash
php artisan tinker
```

Затем выполните:
```php
DB::table('products')->delete();
DB::table('categories')->delete();
DB::table('units')->delete();
DB::table('media')->where('user_id', 13)->delete();
DB::table('folders')->where('parent_id', 1)->where('user_id', 13)->delete();
exit
```

### 3. Убедиться, что файлы данных на месте

Проверьте наличие файлов:
- `storage/pirogi_data.json` - данные о категориях и товарах
- `storage/pirogi_products_images.json` - карта сопоставления товаров с изображениями
- `storage/pirogi_images_map.json` - общая карта изображений (опционально)

### 4. Запустить seeder

```bash
php artisan db:seed --class=PirogiSeeder
```

Seeder выполнит:
- ✅ Создание 8 категорий с `user_id = 1` (или первый пользователь)
- ✅ Создание папок для каждой категории в медиа-библиотеке
- ✅ Создание 4 единиц измерения с `user_id`
- ✅ Создание ~73 товаров с `user_id`
- ✅ Скачивание изображений с сайта pirogi.ru
- ✅ Сохранение изображений в папки категорий
- ✅ Привязка изображений к товарам

### 5. Проверить результаты

После выполнения seeder проверьте:

```bash
php check_seed_results.php
```

Или вручную:
```bash
php artisan tinker
```

```php
echo "Категории: " . App\Models\Category::count() . "\n";
echo "Товары: " . App\Models\Product::count() . "\n";
echo "Товары с фото: " . App\Models\Product::whereNotNull('image_id')->count() . "\n";
echo "Единицы: " . App\Models\Unit::count() . "\n";
echo "Медиа файлы: " . App\Models\Media::where('user_id', 13)->count() . "\n";
```

## Важные замечания

1. **SSL сертификат**: Seeder отключает проверку SSL (`withoutVerifying()`), что необходимо для скачивания изображений с pirogi.ru

2. **Таймауты**: Если seeder прерывается по таймауту, можно увеличить `max_execution_time` в `php.ini` или запустить через CLI без ограничений

3. **Права доступа**: Убедитесь, что папка `public/upload` имеет права на запись (755 или 777)

4. **Пользователь**: Seeder автоматически использует первого пользователя из базы данных. Если нужно использовать конкретного пользователя, измените логику в `PirogiSeeder.php`

5. **Повторный запуск**: Seeder использует `firstOrCreate`, поэтому можно запускать его несколько раз - дубликаты не создадутся

## Структура сохранения изображений

Изображения сохраняются в структуре:
```
public/upload/common/
  ├── salaty/          (Салаты)
  ├── supy/            (Супы)
  ├── vtorye-bliuda/   (Вторые блюда)
  ├── garniry/         (Гарниры)
  ├── pirogi-sytnye/   (Пироги сытные)
  ├── pirogi-sladkie/  (Пироги сладкие)
  ├── vypecka/         (Выпечка)
  └── bliny/           (Блины)
```

Каждая папка содержит:
- Оригинальные изображения (.jpg)
- WebP версии (в подпапке webp/)
- Варианты размеров (в подпапке variants/)

## Если изображения не скачиваются

1. Проверьте доступность сайта pirogi.ru
2. Проверьте интернет-соединение сервера
3. Проверьте файл `storage/pirogi_products_images.json` - он должен содержать карту сопоставления
4. Проверьте логи Laravel: `storage/logs/laravel.log`
