# Сборка админки при деплое

## Проблема
На сервере нет npm, поэтому при деплое сообщение: **«npm install: пропущен (npm недоступен на сервере)»**.  
В итоге после `git pull` отдаётся **старая** собранная админка (Vue/Inertia), и новые поля в форме магазина (бот, приветствие, тест webhook) не видны.

## Решение

### Вариант 1: Собрать админку локально и закоммитить (рекомендуется, если на сервере нет Node)

1. **Локально** в корне проекта выполнить:
   ```bash
   npm run build
   ```
2. В репозитории **разрешён коммит** `public/build` (в `.gitignore` эта папка закомментирована).
3. Добавить и закоммитить сборку:
   ```bash
   git add public/build
   git commit -m "build: admin assets (ShopForm bot, welcome, webhook)"
   git push
   ```
4. Запустить деплой как обычно. После `git pull` на сервере подтянется новая сборка, и форма магазина будет с новыми полями.

### Вариант 2: Настроить npm на сервере
Если на сервере появится Node/npm, деплой уже умеет после `npm install` запускать **`npm run build`** — тогда сборка будет выполняться на сервере и коммитить `public/build` не нужно.

---

**После обновления:** откройте https://crm.neeklo.ru/admin/shops/1/edit — должны отображаться:
- кнопки «Проверить токен» и «Тест webhook»;
- блок «Наименование бота»;
- блок «Приветственное сообщение (команда /start)» с полями текст и фото (ID медиа).
