  КОМАНДЫ ДЛЯ ПРОВЕРКИ И ВЫПОЛНЕНИЯ DEPLOY
═══════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│ 1. ПРОВЕРКА НА СЕРВЕРЕ (через веб-интерфейс хостинга)       │
└─────────────────────────────────────────────────────────────┘

1. Войдите в панель управления хостингом (cPanel/Plesk/другая)
2. Откройте "Файловый менеджер" или "File Manager"
3. Перейдите в директорию: ~/crm.neeklo.ru/public_html

Проверьте наличие файлов:
✓ .env (должен содержать DEPLOY_TOKEN)
✓ .git (директория должна существовать)
✓ storage/ (должна существовать с правами 775)
✓ bootstrap/cache/ (должна существовать с правами 775)

Через файловый менеджер проверьте .env:
- Откройте .env файл
- Убедитесь что есть строка: DEPLOY_TOKEN=4dc714198d297556aa76904a976abbff1ab3707f4d4533eecbc3c037a62dae07

Если нужно настроить git через веб-интерфейс:
- Используйте "Terminal" или "SSH Access" в панели управления
- Или используйте команды через файловый менеджер (если есть такая функция)


┌─────────────────────────────────────────────────────────────┐
│ 2. ПРОВЕРКА ДОСТУПНОСТИ САЙТА ЧЕРЕЗ HTTPS                   │
└─────────────────────────────────────────────────────────────┘

Откройте в браузере:
https://crm.neeklo.ru

Проверьте:
✓ Сайт открывается
✓ Нет ошибок 500
✓ Отображается Laravel приложение

Проверьте API endpoint:
https://crm.neeklo.ru/api/deploy

Должен вернуть JSON с ошибкой авторизации (это нормально, значит endpoint работает):
{
  "success": false,
  "message": "Неверный секретный ключ"
}


┌─────────────────────────────────────────────────────────────┐
│ 3. НАСТРОЙКА ЛОКАЛЬНОГО .env                                 │
└─────────────────────────────────────────────────────────────┘

Откройте файл: c:\OSPanel\domains\ADMIN-CRM\crm\.env

Убедитесь, что есть строки:
DEPLOY_SERVER_URL=https://crm.neeklo.ru
DEPLOY_TOKEN=4dc714198d297556aa76904a976abbff1ab3707f4d4533eecbc3c037a62dae07

Если нет - добавьте их в конец файла.


┌─────────────────────────────────────────────────────────────┐
│ 4. ПРОВЕРКА ЛОКАЛЬНОГО GIT                                   │
└─────────────────────────────────────────────────────────────┘

cd c:\OSPanel\domains\ADMIN-CRM\crm

# Проверка remote
git remote -v

# Проверка ветки
git branch

# Проверка статуса
git status


┌─────────────────────────────────────────────────────────────┐
│ 5. ТЕСТИРОВАНИЕ DEPLOY (dry-run)                             │
└─────────────────────────────────────────────────────────────┘

cd c:\OSPanel\domains\ADMIN-CRM\crm

# Тест без реальных изменений
php artisan deploy --dry-run

# Тест без сборки
php artisan deploy --dry-run --skip-build


┌─────────────────────────────────────────────────────────────┐
│ 6. ВЫПОЛНЕНИЕ DEPLOY                                         │
└─────────────────────────────────────────────────────────────┘

cd c:\OSPanel\domains\ADMIN-CRM\crm

# Базовый deploy
php artisan deploy

# С кастомным сообщением
php artisan deploy --message="Описание изменений"

# Без сборки фронтенда
php artisan deploy --skip-build

# С выполнением seeders
php artisan deploy --with-seed

# С отключением проверки SSL (если проблемы с сертификатом)
php artisan deploy --insecure


┌─────────────────────────────────────────────────────────────┐
│ 7. ПРОВЕРКА DEPLOY ENDPOINT ЧЕРЕЗ HTTPS (тест)              │
└─────────────────────────────────────────────────────────────┘

Можно протестировать endpoint через curl или Postman:

# Тест с неверным токеном (должна быть ошибка 403)
curl -X POST https://crm.neeklo.ru/api/deploy \
  -H "X-Deploy-Token: wrong-token" \
  -H "Content-Type: application/json"

# Тест с правильным токеном (должен выполнить deploy)
curl -X POST https://crm.neeklo.ru/api/deploy \
  -H "X-Deploy-Token: 4dc714198d297556aa76904a976abbff1ab3707f4d4533eecbc3c037a62dae07" \
  -H "Content-Type: application/json" \
  -d '{"branch":"main","run_seeders":false}'

Или через PowerShell:
$headers = @{
    "X-Deploy-Token" = "4dc714198d297556aa76904a976abbff1ab3707f4d4533eecbc3c037a62dae07"
    "Content-Type" = "application/json"
}
$body = @{
    branch = "main"
    run_seeders = $false
} | ConvertTo-Json
Invoke-RestMethod -Uri "https://crm.neeklo.ru/api/deploy" -Method Post -Headers $headers -Body $body


┌─────────────────────────────────────────────────────────────┐
│ 8. ПРОВЕРКА ПОСЛЕ DEPLOY (через HTTPS)                       │
└─────────────────────────────────────────────────────────────┘

1. Откройте сайт в браузере:
   https://crm.neeklo.ru

2. Проверьте, что сайт работает без ошибок

3. Через веб-интерфейс хостинга проверьте логи:
   - storage/logs/laravel.log
   - Ищите записи с "deploy" или "Деплой"

4. Проверьте через API статус (если есть такой endpoint):
   https://crm.neeklo.ru/api/health
   (если такой endpoint существует)


┌─────────────────────────────────────────────────────────────┐
│ 9. ПЕРВЫЙ DEPLOY (если проект еще не в git на сервере)     │
└─────────────────────────────────────────────────────────────┘

ВАЖНО: Для первого деплоя все равно нужен доступ к серверу через:
- SSH (если доступен)
- Terminal в панели управления хостингом
- Или через веб-интерфейс файлового менеджера

Через Terminal в панели управления:

cd ~/crm.neeklo.ru/public_html
git init
git remote add origin https://github.com/letoceiling-coder/admin-crm.git
git fetch origin
git checkout -b main
git reset --hard origin/main
chmod -R 775 storage bootstrap/cache
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:clear
php artisan cache:clear

Затем на локальной машине:
cd c:\OSPanel\domains\ADMIN-CRM\crm
php artisan deploy


┌─────────────────────────────────────────────────────────────┐
│ 10. АЛЬТЕРНАТИВА: Ручная загрузка через FTP/Файловый менеджер│
└─────────────────────────────────────────────────────────────┘

Если нет доступа к Terminal/SSH:

1. Через файловый менеджер хостинга:
   - Загрузите все файлы проекта
   - Убедитесь что .env настроен правильно
   - Установите права 775 на storage и bootstrap/cache

2. Затем используйте deploy команду локально:
   cd c:\OSPanel\domains\ADMIN-CRM\crm
   php artisan deploy --skip-build
   
   Команда отправит POST запрос на https://crm.neeklo.ru/api/deploy
   который выполнит git pull и обновление на сервере
